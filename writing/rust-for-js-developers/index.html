Mental Model Shifts: JS Developer Learning Rust

Rana Aryan•February 18, 2026•8 min read

Fighting the Borrow Checker

Coming from TypeScript, where garbage collection frees you from thinking about memory allocations, my first weeks with Rust were filled with compiler error messages.

The compiler wasn't being strict out of spite: it was teaching me to think explicitly about data ownership, mutability, and lifetime scope.

How Rust Improved My TypeScript Code

- **Explicit Nullability & Result Types**: Rust's `Option` and `Result` enums inspired me to handle error boundaries explicitly in TypeScript instead of throwing unhandled exceptions. - **Immutability by Default**: Explicitly marking variables as mutable in Rust made me appreciate `const` and immutable state updates in React. - **Understanding Memory Boundaries**: Learning how stack and heap allocations work in Rust gave me better insight into V8 engine memory usage when dealing with large JS data structures.

Learning a lower-level language doesn't replace high-level web tools: it makes you a much sharper software engineer when using them.
